# Pet Nameplates Implementation Plan

**Goal:** Draw every Pet's Name directly above that Pet in the farm view, without reserving space for mood emotes, and let the Farmer hide all Nameplates in settings.

**Status:** The implementation is complete. Automated verification is complete; the visual checklist at the end still needs to be run in Cursor after reloading its window.

**Architecture:** The farm view renders Pet sprites and mood emotes on a scaled canvas. Nameplates are HTML elements in a separate, unscaled layer above that canvas, as required by [ADR-0001](../../adr/0001-nameplates-sit-outside-the-scaled-canvas.md). Every Pet owns one Nameplate. On each frame, the Pet's game position is converted to screen pixels and written to that element.

The Nameplate is anchored to the horizontal centre and first visible row of the Pet's current sprite frame:

```text
x = (pet.x + pet.width / 2) * scale
y = (pet.y + visibleTopInset - nameGap) * scale
```

`visibleTopInset` is the first row with a nontransparent pixel in the current animation frame, measured from that frame's top edge. It is cached for each image and frame so the alpha pixels are read only once. `moodElevation` is used only to position the mood emote on the canvas. A visible emote does not move the Nameplate.

**Tech Stack:** TypeScript (strict), esbuild, VS Code webview, Canvas 2D, HTML and CSS.

## Constraints

- Use the vocabulary in `CONTEXT.md`: a **Pet** has a **Name**, drawn as a **Nameplate**.
- Keep Nameplates outside the scaled canvas so their text remains sharp and the same size at every farm scale.
- Keep a long Name whole in saved data; shorten it only visually with CSS ellipsis.
- Keep the complete Nameplate within the webview bounds.
- Nameplates must not take part in Pet hit testing or intercept pointer events.
- Hide Nameplates in decor mode, for inactive Pets, and when `stardew-pets.showNames` is off.
- `media/main.js` is generated by `npm run build-game`; never edit it by hand.
- Add no runtime or development dependencies.

Position the Nameplate from the visible pixels of the Pet's current sprite frame, not from its mood emote:

```ts
//Name plate
static nameGap: number = 2;

updateNameplate(show: boolean) {
    this.#nameplate.hidden = !show || !this.name;
    if (this.#nameplate.hidden) return;

    //Anchor the name plate above the visible sprite, not its transparent frame padding
    const xAnchor = Math.round((this.pos.x + this.size.x / 2) * Game.scale);
    const yAnchor = Math.round((this.pos.y + this.#visibleTopInset() - PetCharacter.nameGap) * Game.scale);

    const width = this.#nameplate.offsetWidth;
    const height = this.#nameplate.offsetHeight;
    const left = Util.clamp(
        Math.round(xAnchor - width / 2),
        0,
        Math.max(0, Game.windowSize.x - width)
    );
    const top = Util.clamp(
        yAnchor - height,
        0,
        Math.max(0, Game.windowSize.y - height)
    );

    this.#nameplate.style.left = `${left}px`;
    this.#nameplate.style.top = `${top}px`;
}
```
